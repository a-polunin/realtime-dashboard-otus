Прежде чем разговаривать об атрибутах нужно определиться с драйверами

D1 - Источники данных. Их может быть много и они не сходятся мгновенно
D2 - Неравномерная нагрузка. Во время матча приходит много пользователей
D3 - Низкая задержка и равномерная доставка. Пользователи по всему миру должны видеть одинаковую картину.
D4 - Разные классы событий. Гол, замена, время матча и тд - это редкие события, которые обновляются не часто. Процент точности передач, xG, владение мячом - это то, что пересчитывается постоянно
D5 - Возможность откатывать изменения. Пример: команда забила гол, но потом через VAR его отменили. Нужно отменить не только гол, но и сопутствующую статистику, на которую этот гол повлиял

Теперь определимся с атрибутами качества в соответствии с драйверами

| Атрибут                    | Тип     | Атрибут в ISO 25010    | К какому драйверу относится |
| -------------------------- | ------- | ---------------------- | --------------------------- |
| Надежность                 | runtime | Reliability            | D1                          |
| Производительность         | runtime | Performance Efficiency | D2, D3                      |
| Функциональная пригодность | runtime | Functional Suitability | D3, D4, D5                  |
